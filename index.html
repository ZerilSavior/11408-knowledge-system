框架说明与延伸方式

这个框架如何生长

  • 骨架为「学科 → 章节 → 小节 → 考点」四级结构，完整收录 2026 考纲条目。
  • 每个考点预留四个知识板块：核心概念、重点难点、常考题型、关联考点，当前显示「待延伸」空态。
  • 后续只需告诉我「延伸 XX 考点」，即可逐层向下填充知识内容；也可以在顶栏「我的笔记」中自由添加自己学到的新知识点笔记（支持 Markdown、代码块与手绘涂鸦），或用「思维导图」像幕布 / XMind 一样列大纲、画导图，无需对话。
  • 学习状态（未学 / 学习中 / 已掌握）与笔记自动保存在浏览器本地，支持一键导出 JSON 备份。
