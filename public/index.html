框架说明与延伸方式

这个框架如何生长

  • 骨架为「学科 → 章节 → 小节 → 考点」四级结构，完整收录 2026 考纲条目。
  • 每个考点均设四个知识板块：核心概念、重点难点、常考题型、关联考点，已按考纲系统填充，可继续在详情页补充与订正。
  • 后续只需告诉我「延伸 XX 考点」，即可逐层向下填充知识内容；也可以在任意考点详情页添加自己的「笔记 / 导图 / 错题」并自动关联到该考点，或在顶栏「学习中心」统一管理——笔记支持 Markdown、代码块与手绘涂鸦，导图支持大纲 / 思维导图双视图，错题可标记待复习 / 已掌握，登录后云端同步。
  • 学习状态（未学 / 学习中 / 已掌握）与笔记自动保存在浏览器本地，支持一键导出 JSON 备份。
