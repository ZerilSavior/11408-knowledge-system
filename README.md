# 11408 考研计算机统考 · 知识体系

考研 11408（计算机学科专业基础综合）个人知识体系管理页面。把考试大纲、考点和知识点笔记组织成可交互的双栏知识树，并支持**学习进度云端同步**——在任意设备上记录"已掌握"状态，随时续学。

## 功能特性

- **知识树导航**：按学科（数据结构 / 计算机组成原理 / 操作系统 / 计算机网络）组织考点大纲
- **双栏联动**：左侧考点大纲，右侧知识点详情，宽窄可拖拽调节
- **进度标记**：考点可标记"已掌握"，进度自动保存
- **云端同步**：学习进度存入云端数据库（Cloudflare D1），多设备同步，无需服务器
- **本地兜底**：云端不可用时自动回退到浏览器本地存储，不丢数据
- **学科导航**：侧边栏可隐藏，专注阅读

## 技术架构

```
┌─────────────────┐     ┌──────────────────────────┐
│  浏览器 index.html │ ──▶ │ Cloudflare Pages Functions │
│ （页面 + 本地兜底）  │     │        /api/state          │
└─────────────────┘     └────────────┬─────────────┘
                                     ▼
                          ┌──────────────────────┐
                          │ Cloudflare D1 数据库   │
                          │ （SQLite 兼容，免费）     │
                          └──────────────────────┘
```

| 组件 | 说明 | 成本 |
|---|---|---|
| Cloudflare Pages | 托管页面 + 后端函数 | 免费 |
| Cloudflare D1 | SQLite 兼容数据库，存储学习进度 | 免费（5GB / 每天 10 万次读写） |
| 前端 | 纯原生 HTML/CSS/JS，零依赖 | — |

## 本地运行（可选）

需要 Node.js ≥ 22.5：

```bash
node --no-warnings server.js
# 打开 http://localhost:3000
```

不运行本地服务器也可以直接打开 `index.html` 使用（此时进度仅存浏览器本地）。

## 云端部署

### 方式一：Cloudflare Pages + D1（推荐，永久免费）

1. 注册/登录 [Cloudflare](https://dash.cloudflare.com)（支持 GitHub 登录）
2. 创建 **D1 数据库**（如 `k408-db`）
3. 创建 **Pages 项目**，连接到本仓库，框架预设选 `None`，构建命令和输出目录留空
4. 项目设置 → 函数 → **D1 数据库绑定**，变量名填 `DB`，选择刚创建的数据库
5. 重新部署，即可通过 `https://<项目名>.pages.dev` 访问

首次请求会自动创建 `kv` 数据表，无需手动迁移。

### API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/state` | 获取学习进度（无数据时返回 `data: null`） |
| PUT | `/api/state` | 保存完整学习进度 JSON |

## 数据说明

- 学习进度（考点掌握状态、笔记等）以单个 JSON 对象存储在 D1 数据库的 `kv` 表中
- 前端优先读写云端；云端不可用时自动回退浏览器 `localStorage`，恢复后重新建档
- 数据可通过 Cloudflare 控制台 → D1 → 数据库 → 导出，随时备份
